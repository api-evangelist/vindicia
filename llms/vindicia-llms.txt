# Vindicia

> Vindicia (an Amdocs company) is a subscription-billing and failed-payment recovery platform for subscription businesses. Its products include Vindicia Subscribe (subscription management / recurring billing) and Vindicia Retain (machine-learning-driven recovery of failed recurring payments), plus Vindicia Connect (identity/IDP with OAuth2/OIDC). It exposes REST APIs (and a legacy CashBox SOAP API), documents webhooks, API-key and OAuth2 authentication, and error-code references.

## APIs
- [Vindicia Subscribe REST API Guide](https://docs.vindicia.com/bundle/b_Subscribe_REST_API_Guide/page/topics/Overview.html): Recurring billing, subscriptions, accounts, tokens, and payment operations.
- [Vindicia Retain REST API Guide (OpenAPIs)](https://docs.vindicia.com/bundle/b_retainRESTAPIGuideOpenAPIs/page/topics/retainAPIOverview_c.html): Failed-payment recovery API.
- [Vindicia Retain V1.5 API Reference](https://docs.vindicia.com/bundle/b_Retain_V1.5_API_Reference_Guide/page/topics/Vindicia_Retain_API_Overview.html): Versioned Retain reference.
- [Vindicia Connect (OAuth2 / OpenID Connect)](https://docs.vindicia.com/bundle/b_ConnectProductDescription/page/topics/oAuth2andOpenIDConnect_c.html): Identity and end-user authentication.
